# Dev Showcase

Repositório para publicar prévias independentes de sites de clientes.

## Estrutura

```text
/
├── index.html
└── previews/
    ├── barbearia-philereno/
    ├── i-pet-you/
    └── brasa-burger/
        ├── index.html
        ├── styles.css
        ├── script.js
        └── assets/
```

Cada cliente fica em uma pasta própria dentro de `previews/`. Ao adicionar uma nova prévia, inclua também seu cartão na página inicial.
